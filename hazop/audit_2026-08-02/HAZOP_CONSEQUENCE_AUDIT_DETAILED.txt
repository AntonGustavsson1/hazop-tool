SWEDISH LANGUAGE QUALITY GUIDELINES FOR HAZOP CONSEQUENCE CHAINS
=================================================================================

CRITICAL TERMINOLOGY (Process Safety Swedish):

Flow/Pressure Terms:
  - Reducerat flöde = Reduced flow
  - Låg nivå / Låga nivåer = Low level
  - Högt tryck / Övertryck = High pressure / Overpressure
  - Lågt tryck / Undertryck = Low pressure / Vacuum
  - Plötslig stoppning = Sudden stoppage
  - Okontrollerat flöde = Uncontrolled flow
  - Flödesomkastning = Flow reversal

Equipment Failures:
  - Ventil stängd / felar stängd = Valve closed / fails to close
  - Ventil öppen / felar öppen = Valve open / fails to open
  - Ventil läcker = Valve leaking
  - Pumpe stannar / felar = Pump stops / fails
  - Sensor faller bort = Sensor fails/drops out
  - Instrument felar = Instrument malfunctions

Safety Consequences:
  - Överstigning av kritisk temperatur = Exceeding critical temperature
  - Exoterm reaktion / runaway = Exothermic reaction / runaway
  - Personskador = Personal injury
  - Miljökontaminering = Environmental contamination
  - Explosionsrisik = Explosion risk
  - Brandrisik = Fire risk
  - Trycksprängning = Pressure rupture

GRAMMAR & STYLE RULES:

✓ DO:
  - Start each step with CAPITAL LETTER: "Reducerat flöde" NOT "reducerat flöde"
  - Use active voice: "Ventilen stänger" BETTER THAN "ventilen är stängd"
  - Be SPECIFIC: "Vattentrycket i kölanläggningen sjunker till 5 bar"
    NOT just "tryck sjunker"
  - Use CONSISTENT Swedish throughout chain: Never mix "flow" + "flöde"
  - Include UNITS when numeric: "Temperaturen stiger till 150°C"
    NOT just "temperatur stiger"
  - Use present tense for process flow: "Vätskan läcker ut"
    INSTEAD OF past: "vätskan har läckt ut"

✗ DON'T:
  - Mix languages: "Flöde decreases" is WRONG
  - Use tag codes as descriptions: "11VI:4304" is NOT a consequence
  - Make VAGUE statements: "Något dåligt händer" (Something bad happens)
  - Use placeholder text: "Etc." or "..." shows incomplete work
  - Abbreviate terms: Use "Tryckpåkänning" NOT "P_k" or "pres"
  - Passive voice when active is clearer: NOT "vätskan är blockerad"
    BETTER: "vätskan blockeras av..." or "blockering av vätskan"
  - Leave steps incomplete: 3/5 steps means 40% of data missing

CONSISTENCY RULES:

  Same root cause = Similar consequence chain pattern
    Example: If two valves fail the SAME WAY (both felar stängd),
    their consequence chains should follow similar logic:
      Del 1: [Component] stays [position]
      Del 2: [System response] to that state
      Del 3: [Process impact]
      Del 4: [Equipment stress]
      Del 5: [Final safety/business consequence]

  Consequence severity should progress:
    Del 1: Local immediate effect
    Del 2: Propagation through system
    Del 3: Process-level impact
    Del 4: Equipment or secondary effects
    Del 5: Final risk (safety, environmental, business)

DATABASE QUERY - FIND DUPLICATE RECORDS
=================================================================================

Run this SQL to identify any other duplicate consequences:

  SELECT cause_id, description, COUNT(*) as cnt
  FROM consequences
  GROUP BY cause_id, description
  HAVING COUNT(*) > 1
  ORDER BY cnt DESC;

This will show any consequences that share both the same cause_id AND
the same description text. If records appear with COUNT > 1, they are
duplicates that should be consolidated.

Run this to show all consequences for cause 8 (reglerventil felar stängd):

  SELECT
    c.id,
    c.cause_id,
    c.description as cons_desc,
    (SELECT COUNT(*) FROM consequence_steps WHERE consequence_id = c.id) as step_count
  FROM consequences c
  WHERE c.cause_id = 8;

This will show:
  ID 2: "O/CO/C" with 0 steps
  ID 3: "11VI:4304" with 0 steps
  ID 4: "11VI:4304" with 0 steps (likely duplicate of 3)
