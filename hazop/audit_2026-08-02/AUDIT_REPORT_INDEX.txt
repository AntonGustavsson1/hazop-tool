ROOT CAUSES OF ISSUES
================================================================================

Why tag codes instead of descriptions?
  → Likely copy-paste error or incomplete data entry
  → UI allowed saving without proper validation
  → User may have intended to come back and complete

Why incomplete consequence chains?
  → Database doesn't enforce "all 5 steps required"
  → Application UI doesn't warn about missing steps
  → User may not understand 5-step methodology
  → Process/workflow not clearly documented

Why duplicates exist?
  → No unique constraint preventing duplicates
  → Copy-paste without delete
  → No duplicate detection in application
  → Data quality checks missing

Prevention going forward:
  → Add validation rules to database layer
  → Create templates and guidance documents
  → Implement UI warnings for incomplete records
  → Establish peer review before final save
